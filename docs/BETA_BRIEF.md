## Не баг (известно сейчас)

| Тема | Поведение |
|------|-----------|
| Табы | На чате / нардах / профиле контакта свайп между табами **выключен** — только иконки таб-бара |
| Смена таба из чата | Вернулись на «Чаты» → снова **список**, не открытая комната |
| Блок / «Кто может писать» | Только на **этом** телефоне |
| Переслать / закрепить | «В разработке» |
| Звонки | «Скоро» |
| Вкладка Poker | Tamagotchi |
| Aria | В release нужен VPS; без `EXPO_PUBLIC_ARIA_API_URL` бот может молчать |
