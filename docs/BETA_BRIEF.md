## Для тестеров (когда будет APK)

1. Скачать APK (ссылка: _TBD_).
2. Android: «Установить из неизвестных источников» для файла / браузера.
3. Установить **Vault** (`com.vault.messenger`), не «Vault (разработка)».
4. Регистрация / вход → выбрать @handle → **Пригласить** (QR или код от организатора).
5. Чаты → открыть диалог → текст, медиа, голос (по желанию).

**Куда слать баги:** _Telegram / email — TBD_

В сообщении укажите: модель телефона, Android версия, что делали, скрин/видео, время (МСК).

## Известные ограничения (не баг)

| Тема | Как сейчас |
|------|------------|
| Свайп табов | На экране чата / нард / профиль контакта горизонтальный свайп табов **выключен** — только кнопки таб-бара |
| Смена таба с открытым чатом | Вернулись на «Чаты» — снова **список**, не комната (так задумано в pager) |
| Блокировка / «Кто может писать» | Только **на этом телефоне** (AsyncStorage), не на сервере |
| Переслать / закрепить | «В разработке» |
| Звонки | Заглушка «скоро» |
| Вкладка Poker | Tamagotchi, не покер |
| Aria | Нужен сервер на VPS (`EXPO_PUBLIC_ARIA_API_URL`); без VPS в release APK бот может не отвечать |
