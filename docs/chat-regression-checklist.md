# Chat regression checklist (~10 мин)

Ручной прогон на **dev-сборке** или **release APK** перед раздачей / после крупных правок чата.

**Commit:** `git rev-parse --short HEAD` → записать в баг-репорт при падении.

---

## Навигация

- [ ] Табы **Chats ↔ Contacts ↔ Profile** (иконки таб-бара)
- [ ] Из чата смена таба → возврат на «Чаты» = **список**, не открытая комната
- [ ] Профиль контакта: скroll, hardware back / свайп назад (Android)

## Сообщения (два аккаунта)

- [ ] Текст туда-обратно (E2E — не plaintext в БД)
- [ ] Фото / голос (если включено в тесте)
- [ ] Reply, edit, delete (если доступно в UI)
- [ ] Закрепить сообщение (контекстное меню)
- [ ] Read receipts / «прочитано» (по возможности)

## Комната / медиа

- [ ] Fullscreen image / video viewer
- [ ] Эфемерные сообщения (countdown + исчезновение) — опционально

## Игра + чат

- [ ] GameScreen: остров нард, бросок костей, чат не ломается
- [ ] KB / emoji panel: доска восстанавливается после закрытия

## Aria (если VPS / URL настроен)

- [ ] Панель Aria на списке чатов
- [ ] Ответ бота в чате Aria

## Smoke (авто, перед ручным)

```bash
npm run smoke
npm run smoke:api    # .env.smoke
```
