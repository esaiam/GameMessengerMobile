# Чат — ручная регрессия перед/после оптимизаций

Перед релизом изменений по производительности чата пройти за ~2–3 минуты:

1. Открыть чат с историей, проскроллить вверх и вниз (инерция без залипаний).
2. Отправить текстовое сообщение — появляется у собеседника/в ленте как раньше.
3. Ответ (reply) на сообщение — превью и отправка работают.
4. Долгое нажатие / контекстное меню (если включено) — без краша.
5. Режим выбора сообщений — включить, выбрать несколько, выйти из режима.
6. Голосовое сообщение — запись и воспроизведение (если используете).
7. Медиа (фото/видео) — открытие полноэкранно и закрытие.

Опционально: React DevTools Profiler — те же шаги, зафиксировать число коммитов `Chat` и `MessageRow` «до» изменений.
